# uRunCalc

Тёмный калькулятор на Flutter с точной рациональной арифметикой и наглядным
отображением дробей.

## Возможности

- Точные вычисления с рациональными числами: `1/3 + 1/6` даёт ровно `1/2`,
  а `0.1 + 0.2` — ровно `0.3`.
- Дроби отображаются вертикально (числитель над знаменателем) прямо в поле
  ввода: `1/3`, `(1+2)/4`, `1/2/3`.
- Дробь в основании степени автоматически берётся в скобки: `(2/3)^2`.
- Результат-дробь показывается вместе с десятичным значением:
  - `1/2` → дробь `1/2` и `= 0.5`;
  - `1/3` → дробь `1/3` и `≈ 0.333333333333333`;
  - иррациональные результаты (`sqrt(2)`, `2^0.5`) показываются десятичным
    числом со знаком `≈`.
- Большие и очень маленькие числа автоматически переводятся в научную запись
  (`1.26765060023e+30`), чтобы не превращаться в нечитаемую строку.
- История последних восьми вычислений:
  - пустое поле (или только что показанный результат) — выражение из истории
    подставляется в поле;
  - если в поле уже что-то введено — итоговое значение дописывается в конец
    выражения, а ввод не затирается.
- Долгое нажатие на `C` очищает историю.
- Поддержка аппаратной клавиатуры на десктопе и в вебе.
- Тактильный отклик на Android/iOS, семантические метки для screen reader.
- Адаптивная раскладка: в портретной ориентации клавиатура снизу, в
  альбомной — справа, прижата к краю экрана. В режиме `Ultra` в альбомной
  ориентации показываются только таблица и, при вводе, клавиатура, а кнопка
  выбора режима скрывается, чтобы оставить максимум места таблице.
- Переключение режимов кнопкой в левом верхнем углу: `Ultra`, `Pace`, `Time`,
  `Simple` и `Info`. При первом запуске открыт `Ultra`. Состояние каждого
  режима сохраняется при переключении. Последний выбранный режим запоминается
  при сворачивании и выходе из приложения и восстанавливается при следующем
  запуске. В интерфейсе и на иконке приложение называется `uRunCalc`.

## Режимы

### Simple

Обычный калькулятор с точной арифметикой, дробями, процентами и историей.
Клавиатура и поле ввода используют увеличенный шрифт; поле ввода ещё и жирное.
Строки истории всегда одного размера.

### Pace

Калькулятор темпа, расстояния и времени. Верхний блок
`[Темп] [Расстояние] [Время]`: выберите, что нужно найти, и заполните два
других значения. Время вводится отдельно в днях, часах, минутах и секундах.
Таблица чекпойнтов вынесена в отдельный режим `Ultra`.

### Ultra

Таблица чекпойнтов мероприятия. Перед таблицей расположены кнопки:

- `[мероприятие]` — выбор мероприятия и дистанции; кнопка занимает примерно
  половину ширины экрана. По умолчанию выбрано `GRUT · T100`. В меню есть
  `GRUT` (`T100` — 6 ПП, `T80` — 6 ПП, `T50` — 4 ПП), `Mad Fox Ultra` (`VR` —
  9 ПП, `50M` — 5 ПП, `K70` — 4 ПП, `K40` — 2 ПП), а также добавление и
  удаление мероприятий и дистанций. Новое мероприятие создаётся по названию,
  новая дистанция — по названию и количеству ПП. Для `GRUT · T100` и
  `Mad Fox Ultra · VR` новые таблицы сразу заполнены временем `Лимит` и
  расстояниями; остальные дистанции начинаются с пустой таблицы. Пустая
  таблица этих дистанций из старой версии заполняется один раз, уже введённые
  данные не перезаписываются, а очищенная пользователем таблица не заполняется
  повторно.
- `[+−]` — диалог изменения количества колонок таблицы. При уменьшении
  удаляются колонки справа.
- `[замок]` — кнопка без подписи, только с символом замка. Меню фиксации:
  - `Зафиксировать лимиты` — только ряды `Лимит` и `Расстояние` становятся
    только для чтения; `Разблокировать лимиты` возвращает им ввод;
  - `Зафиксировать все` — все поля таблицы становятся только для чтения;
    `Разблокировать все` снимает фиксацию со всех полей;
  - `Зафиксировать в бумаге` — открывает диалог печати таблицы. Можно выбрать
    вертикальную или горизонтальную ориентацию и отправить документ на сетевой
    принтер через системный диалог или сохранить его в PDF. В бумажном макете
    шрифт таблицы увеличен, жирные колонки обведены чёрной рамкой, а дни
    выделены по очереди слабым серым фоном: первый день без фона, второй с
    фоном и так далее. Печать не меняет состояние фиксации таблицы.
  Состояние фиксации сохраняется вместе с таблицей.
- `[масштаб]` — появляется, когда колонок больше 8. Переключает режимы
  «вписать в экран» и «стандартный размер с горизонтальной прокруткой». По
  умолчанию таблица масштабируется.

У каждого мероприятия и дистанции своя таблица: при переключении введённые
значения не сбрасываются, а при возврате восстанавливаются.

В портретной ориентации таблица содержит 11 строк. Названия рядов заметок,
`Лимит`, `Расстояние`, `Темп сегмента`, `Плановый темп`, `Вода` и `Еда` не
показываются; подпись остаётся только у ряда `План`.

- заметки: `Start`, числа `1…N` и `Finish`; нажатие на клетку открывает
  текстовый ввод. Номер ПП показывается крупным белым шрифтом. Ряд заметок
  вдвое выше остальных, а текст заметки автоматически подстраивается под
  ширину клетки: помещается одно, максимум два слова, при этом даже длинное
  слово не обрезается;
- `Лимит` — время чекпойнтов `чч:мм`;
- `Расстояние, км` — расстояние от старта. Показываются только те доли, которые
  ввёл пользователь: целое значение остаётся целым (`72`), значение с одной
  десятой — `20.3`, с двумя — `20.35`. Первая клетка показывает `КМ`;
- `Темп сегмента` — темп каждого сегмента от предыдущей точки до текущей.
  Первая клетка ряда содержит `PACE`. Самый маленький темп выделяется красным,
  второй по возрастанию — жёлтым;
- `Общее время - {значение}` и `Темп в лимит - {значение}` — две клетки на
  половину ширины: слева общее время по данным строки `Лимит`, справа итоговый
  темп всей дистанции;
- `План` — план прибытия `чч:мм` белым шрифтом. Если план позже лимита, клетки
  `Лимит` и `План` подсвечиваются красным. Если план раньше лимита менее чем на
  20 минут, клетка `План` подсвечивается жёлтым. При нажатии на клетку курсор
  стоит в начале значения, а первый набранный символ заменяет старое время:
  можно сразу ввести `0855`;
- `Плановый темп` — первая клетка содержит `PACE`, значения выводятся белым.
  Можно заполнить план или темп, второе значение рассчитается по расстоянию
  между ПП. После редактирования плана или планового темпа все последующие
  плановые времена сдвигаются на ту же разницу до последнего сегмента с
  заданным темпом, поэтому итоговые показатели остаются согласованными;
- `Итоговый плановый темп - {значение}` — итоговый плановый темп белым
  шрифтом. Клетку можно выбрать и ввести свой темп: после подтверждения
  пересчёта плана этим темпом заполняется ряд `Плановый темп`, а времена плана
  пересчитываются;
- `Итоговое плановое время - {значение}` — длительность от планового старта
  до планового финиша, а не время суток финиша, белым шрифтом. Его можно
  ввести вручную:
  если плановый старт не заполнен, берётся старт из ряда `Лимит`; после
  подтверждения пересчёта вычисляется средний темп по расстоянию из показателя
  `Финиш`, он записывается в `Итоговый плановый темп` и заполняет ряд
  `Плановый темп`. Введённые плановые данные перезаписываются, кроме явно
  заполненного планового старта;
- `Вода` и `Еда` — произвольный текст с переносом по словам и переводами
  строк. Пока клетка пуста, в первой клетке ряда показывается подсказка `Вода`
  или `Еда`; после начала ввода она исчезает. В ряду `Вода` слова `кола`,
  `вода`, `пиво` и `ягер` окрашиваются соответственно в светло-коричневый,
  голубой, жёлтый и зелёный. Оба ряда имеют максимальную высоту (110 px), а
  длинная запись перетекает в соседние пустые клетки, как в Excel, и
  останавливается перед первой заполненной.

В альбомной ориентации таблица дополнительно получает справа колонку `Total`
(8 строк). Сводных рядов нет: итоговые значения жирным шрифтом стоят прямо в
рядах данных:

- общее время по данным `Лимит` — в ряду `Лимит`;
- итоговый `Темп в лимит` — в ряду `Темп сегмента`;
- `Итоговый плановый темп` — в ряду `План`;
- `Итоговое плановое время` (длительность плана) — в ряду `Плановый темп`.

Освободившееся после удаления сводных рядов место распределено между
оставшимися рядами. Нажатие на итоговое время и темп в лимит показывает
пояснение показателя. Итоговый плановый темп и итоговое плановое время можно
вводить прямо в колонке `Total`: нажатие открывает клавиатуру, `ОК`
показывает подтверждение пересчёта плана, а долгое нажатие показывает
пояснение. В портретной ориентации эти же значения редактируются в отдельных
рядах. В альбомной ориентации подписи рядов, включая `Вода` и `Еда`,
остаются слева от таблицы.

В обеих ориентациях долгое нажатие на клетку ПП (ряда заметок) делает границы
всей колонки жирными и чуть более светлыми серыми; повторное долгое нажатие
возвращает обычную толщину. Оформление действует на все ряды колонки,
сохраняется в таблице и переживает переключение режимов и перезапуск
приложения.

Цветовые статусы дублируются для screen reader: клетка плана читается как
`План, 09:20` с подсказкой «Позже лимита» или «Близко к лимиту», клетка лимита
— как `Лимит, 09:00` с подсказкой «Позже плана». Кнопка-замок без видимой
подписи озвучивается как «Зафиксировать таблицу» или «Разблокировать таблицу»,
а заголовки колонок подсказывают, что долгое нажатие выделяет колонку.

Проверка нового дня выполняется не во время набора, а по завершении ввода: при
переходе в другое поле, нажатии `ОК`, закрытии клавиатуры или тапе вне полей
ввода. Строки `Лимит`, расстояние, темп сегмента, заметки, вода и еда
проверяются по времени `Лимит`, а `План` и `Плановый темп` — по времени
`План`. Первый новый день выделяется тёмно-зелёным, дальнейшие дни — по кругу:
синий, жёлтый, красный, циановый, оранжевый, белый. Стартовый день сохраняет
обычные цвета границ.

Все введённые в Ultra данные (мероприятие и дистанция, колонки, время,
расстояния, планы, заметки, вода и еда, замок) сохраняются в
`SharedPreferences` отдельно для каждой дистанции и переживают
перезапуск приложения и установку новой версии поверх предыдущей. Данные
старой версии автоматически переносятся в новое хранилище; дистанция `100M`
мероприятия `Mad Fox Ultra` переименовывается в `VR` с сохранением введённых
значений.

Клавиатура Ultra скрыта, пока пользователь не нажмёт на поле ввода. Она
выезжает снизу (в портретной ориентации) или справа (в альбомной) и убирается
при нажатии на любое место вне полей ввода. Кнопка `ОК` завершает ввод и
убирает клавиатуру. Если поле находится близко к клавиатуре, таблица
прокручивается так, чтобы поле не оказалось под ней; при вводе в дальнее поле
ближний к клавиатуре край таблицы может уйти под клавиатуру. Кнопки `000` и
`00` в Ultra нет; пустая клетка времени ведёт себя как `00:00`, которое
перезаписывается слева направо: после ввода `07` получится `07:00`.

В альбомной ориентации остаются только таблица и, при вводе, клавиатура:
верхний блок, кнопки над таблицей и кнопка выбора режима скрываются.
Клавиатура имеет верхний ряд `.` `:` `⌫`, три колонки цифр и ряд `0` / `ОК`:
она уже, но плотнее сверху вниз, оставляя максимум места таблице. Все строки
таблицы помещаются на экране телефона.

### Time

Три вкладки:
- `Разница` — интервал между двумя моментами: сначала дата `ддммгггг`, ниже —
  время;
- `Сложить/вычесть` — базовая дата и время, кнопки `+`/`−`, длительность в
  днях, часах, минутах и секундах и результат в виде даты с временем;
- `Конвертер` — перевод времени в общее количество дней, часов, минут и секунд.

При отрицательной разнице перед подписью результата появляется `−`.
Поля ввода не ограничены количеством символов: можно ввести, например,
`1000` минут или `500` часов; такие значения корректно участвуют в разнице,
сложении/вычитании и конвертации.

### Info

Экран с названием приложения и ссылкой на проект:
`https://github.com/reddragondisciple/uRunCalc`. Нажатие на ссылку копирует её
в буфер обмена.

## Управление

| Кнопка | Действие |
| --- | --- |
| `C` | Очистить текущее выражение |
| Долгое нажатие `C` | Очистить историю |
| `⌫` | Удалить последний символ (корень `√(` удаляется целиком) |
| `√` | Квадратный корень |
| `^` | Степень |
| `%` | Процент: `50%` = `0.5`, `200 + 10%` = `220` |
| `000` | Три нуля (только в режиме `Simple`) |
| `=` | Вычислить |

Клавиатура: цифры, `+ - * / ^ % ( ) . =`, `Enter` — вычислить,
`Backspace` — удалить, `Esc`/`C` — очистить, `r` — корень, `x` — умножить.
Аппаратная клавиатура работает в режиме `Simple`; в `Pace`, `Ultra`, `Time` и
`Info` ввод идёт с экранной клавиатуры.

Символьные клавиши (`⌫`, `√`, `×`, `÷`, `%`, `ОК`) имеют словесные подписи для
screen reader; для `⌫` подсказка сообщает, что долгое нажатие очищает поле.

## Процент

Процент работает как в обычном бытовом калькуляторе:

- `50%` → `0.5`
- `200 + 10%` → `220` (10% от 200)
- `200 - 10%` → `180`
- `100 + 10% + 10%` → `121` (каждый процент считается от текущей суммы)
- `200 * 10%` → `20`
- `200 / 10%` → `2000`

В сложении и вычитании процент берётся от левого операнда; в умножении и
делении он остаётся обычным делением на 100.

## Точность

- Основная арифметика (`+ - * /`, целые степени, `%`) точная.
- `sqrt` и дробные степени в общем случае иррациональны, поэтому хранятся как
  рациональное приближение и помечаются знаком `≈`.
- Если корень или дробная степень дают точный результат (`sqrt(4)`, `4^0.5`,
  `(10^14)^0.5`), приближение не используется.
- Десятичная запись округляется до 15 знаков после запятой; для очень больших
  и очень маленьких значений используется научная запись.
- Степени с показателем больше 10 000 и результаты больше примерно 50 000 цифр
  отклоняются с сообщением об ошибке, чтобы не подвешивать интерфейс.

## Структура

Код разделён по слоям:

- `lib/main.dart` — точка входа, `CalculatorApp` / `CalculatorPage`,
  переключение режимов, экран Simple и общая клавиатура; крупные экраны
  вынесены в `part`-файлы, чтобы сохранить доступ к приватному состоянию:
  - `lib/features/pace/pace_view.dart` — Pace и Ultra;
  - `lib/features/time/time_view.dart` — Time;
  - `lib/features/info/info_view.dart` — Info;
  - `lib/features/simple/expression_view.dart` — отрисовка выражений с дробями
    (`_ExpressionView`, `_DisplayParser`);
- `lib/core/rational.dart` — точная рациональная арифметика `Rational`;
- `lib/core/expression_parser.dart` — `ExpressionParser` и `EvalResult`,
  инженерные функции;
- `lib/core/persisted_json_store.dart` — сохранение состояния с debounce,
  последовательной записью и версией схемы;
- `lib/core/app_strings.dart` — словарь текстов интерфейса с русскими
  значениями по умолчанию (первый шаг к локализации); из него берут строки
  Simple, Info, Time, Pace, Ultra, PDF-таблица, подписи клавиш для screen
  reader и сообщения об ошибках вычислений;
- `lib/core/time_math.dart` — общие примитивы форматирования и разбора времени,
  длительности и десятичных чисел;

## Релиз APK на GitHub

Собрать APK:

```bash
flutter build apk --release
```

Универсальный APK появится в
`build/app/outputs/flutter-apk/app-release.apk`. Для меньшего размера можно
собрать отдельные файлы под архитектуры:

```bash
flutter build apk --release --split-per-abi
```

Затем на GitHub:

1. Открыть `https://github.com/reddragondisciple/uRunCalc/releases`.
2. Нажать `Draft a new release`.
3. Указать новый тег, например `v2.0.0`, и заголовок релиза.
4. Приложить APK из `build/app/outputs/flutter-apk/` в раздел `Assets`.
5. Нажать `Publish release`.

Через GitHub CLI то же самое делается командой:

```bash
gh release create v2.0.0 build/app/outputs/flutter-apk/app-release.apk \
  --title "uRunCalc 2.0.0" --notes "Описание изменений"
```

Для публикации в Google Play вместо APK обычно собирают `flutter build appbundle`
и загружают `build/app/outputs/bundle/release/app-release.aab`.

## Перед публикацией

- Android `applicationId` уже заменён на `com.reddragondisciple.uruncalc`.
  Для macOS/iOS при необходимости замените `com.example.calculatorApp` на свой
  идентификатор.
- Release-сборка сейчас подписана debug-ключом. Для публичного релиза создайте
  keystore и настройте `signingConfig` в `android/app/build.gradle.kts`, иначе
  APK не подойдёт для Google Play и обновлений с другим ключом.
